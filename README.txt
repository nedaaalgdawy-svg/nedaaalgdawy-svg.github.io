NEDAA — INTERACTIVE PORTFOLIO HOMEPAGE

This is a ready-to-upload static website. No coding or installation required.

HOW TO PREVIEW
- Open index.html in Chrome or Edge.
- The website works offline except for the optional Google Fonts; online they load automatically.
- Test menu, Arabic/English switch, buttons, and responsive layout.

HOW TO PUBLISH FOR FREE ON GITHUB PAGES
1. Sign in to github.com with your existing account (nedaaalgdawy-svg).
2. Make a NEW public repository named nedaaalgdawy-svg.github.io
   (If this repository already exists, use a different repository and GitHub's project Pages URL.)
3. Upload index.html, styles.css, script.js and the entire assets folder to the repository root.
4. Go to Settings > Pages > Build and deployment.
5. Choose Deploy from a branch, main, / (root), then Save.
6. When GitHub finishes deploying, visit https://nedaaalgdawy-svg.github.io/
   It can take a few minutes to become available.

CUSTOMIZATION
